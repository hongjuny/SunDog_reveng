# Reference rendering attribution

The `a2m-hgr-colour-v1` profile adapts the three-bit neighbor-window method and
palette from StewBC/a2m, `src/machine/video.c`, pinned upstream commit
`d863ad98487639445db16134d260221839cb72e9`:
https://github.com/StewBC/a2m

The repository's own source is dedicated to the public domain under the Unlicense
(external dependencies have separate licenses). The original SunDog game code,
graphics and Apple ROM bytes are not included in this source tree or viewer bundle.
The externally installed reference executable contains its own reference ROMs;
its identity and local transport/source modifications are recorded separately.

This preset matches the selected reference software decoder. It is not a claim
of full analog NTSC simulation or a final calibration to physical hardware.
